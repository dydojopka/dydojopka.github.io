# Dydojopka's business card

Доступ по ссылке: [dydojopka.github.io](https://dydojopka.github.io/)

## Запуск

Требуются Node.js 24 и pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm build
pnpm preview
```
