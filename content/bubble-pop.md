# Bubble Pop

Игра на JavaScript и CreateJS: собирайте группы шариков одного цвета, набирайте очки и не дайте игровому полю опуститься до красной линии.

Отрисовка, управление и анимации в браузере. Игровые правила и сетка вынесены в отдельный модуль.

## Стек

- JavaScript / CreateJS
- HTML / CSS / Canvas

[Открыть проект на GitHub ↗](https://github.com/dydojopka/Bubble-pop)
