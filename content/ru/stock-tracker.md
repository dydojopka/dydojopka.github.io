# Stock Tracker

Веб-приложение для учёта домашних запасов продуктов: остатки, сроки годности, списание и списки покупок.

Авторизация, панель с графиками и автоматическое формирование списка покупок по дефициту запасов.

## Стек

- Java / Spring Boot / Spring Security
- JPA / Thymeleaf / H2 / Maven

[Открыть проект на GitHub ↗](https://github.com/dydojopka/Local-Stock-Tracker)
