# Умный город

Система управления городской инфраструктурой: шесть микросервисов с REST API и общим веб-интерфейсом.

Мой вклад: сервисы пользователей и заявок ЖКХ, авторизация интерфейса, API-контракт и интеграция.

## Стек

- Python / FastAPI / SQLAlchemy
- React / SQLite / Docker Compose
