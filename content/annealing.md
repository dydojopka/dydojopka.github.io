# Поиск ДНФ

Эвристический поиск ДНФ методом имитации отжига. Терминальный интерфейс позволяет настраивать алгоритм и наблюдать график изменения энергии.

Вычисления выполняются в отдельном процессе. Результаты, журнал и график можно сохранить для анализа.

## Стек

- Python / Textual / multiprocessing
- Matplotlib / plotext

[Открыть проект на GitHub ↗](https://github.com/dydojopka/simulated-annealing-dnf)
