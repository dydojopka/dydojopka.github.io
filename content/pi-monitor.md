# Pi Network Monitor

Мониторинг интернет-соединения на Raspberry Pi 5 с дисплеями Waveshare. Показывает ping, потерю пакетов, скорость сети и время работы соединения.

Работа с LCD и OLED-дисплеями через SPI и I²C, управление яркостью аппаратными кнопками.

## Стек

- Python / Raspberry Pi / GPIO
- luma / Pillow / psutil
