# Pi Network Monitor

Internet connection monitoring on a Raspberry Pi 5 with Waveshare displays. Shows ping, packet loss, network speed, and connection uptime.

Controls LCD and OLED displays over SPI and I²C, with hardware buttons for adjusting brightness.

## Tech stack

- Python / Raspberry Pi / GPIO
- luma / Pillow / psutil
