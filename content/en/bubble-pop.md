# Bubble Pop

A game built with JavaScript and CreateJS: match groups of bubbles of the same color, score points, and keep the board from reaching the red line.

Rendering, controls, and animations run in the browser. Game rules and the grid are handled by a separate module.

## Tech stack

- JavaScript / CreateJS
- HTML / CSS / Canvas
