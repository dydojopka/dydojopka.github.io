# Terminal Summer

![Terminal Summer logo](../TS.png)

A terminal adaptation of the visual novel Everlasting Summer. Scenes, backgrounds, and characters are rendered in ANSI/ASCII, with an interface that runs right in the console.

Python, terminal graphics, and an experiment with a familiar game interface.

## Tech stack

- Python / Textual / Rich
- Pillow / pil2ansi
