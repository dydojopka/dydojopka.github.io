# DNF Search

Heuristic search for disjunctive normal forms using simulated annealing. A terminal interface lets you configure the algorithm and follow changes in energy on a chart.

Calculations run in a separate process. Results, logs, and charts can be saved for analysis.

## Tech stack

- Python / Textual / multiprocessing
- Matplotlib / plotext

[View project on GitHub ↗](https://github.com/dydojopka/simulated-annealing-dnf)
