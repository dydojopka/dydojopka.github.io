# Class Schedule Bot

A Telegram bot for class schedules at IMIT, Irkutsk State University. Fetches data from the university website and presents schedules through a button-based interface.

Supports student groups from years one through four and saves user preferences in SQLite.

## Tech stack

- Python / pyTelegramBotAPI
- Requests / SQLite
