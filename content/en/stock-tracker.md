# Stock Tracker

A web application for managing food supplies at home: stock levels, expiration dates, write-offs, and shopping lists.

Includes authentication, a dashboard with charts, and shopping lists generated automatically from stock shortages.

## Tech stack

- Java / Spring Boot / Spring Security
- JPA / Thymeleaf / H2 / Maven

[View project on GitHub ↗](https://github.com/dydojopka/Local-Stock-Tracker)
