# Бот расписания

Telegram-бот с расписанием занятий ИМИТ ИГУ. Получает данные с сайта университета и предоставляет расписание через интерфейс с кнопками.

Поддержка групп 1–4 курсов и сохранение пользовательских настроек в SQLite.

## Стек

- Python / pyTelegramBotAPI
- Requests / SQLite
